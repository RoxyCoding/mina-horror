# Mina Horror

## 木の描画（1.1.0）

バニラの全地上樹種（オーク、トウヒ、シラカバ、ジャングル、アカシア、ダークオーク、マングローブ、サクラ、ペールオーク、ツツジ、ポプラ）と、真紅・歪んだ巨大キノコの描画を変更します。ポプラは黄・橙・赤の3色の葉に対応。導入済みのワールドにも、次のクライアント起動から適用されます。

- 丸い幹、樹皮の凹凸、先細りの枝、地面に接する根元、2×2の太い幹、斜めの原木間をつなぐ枝。
- 樹種ごとの写真調の樹皮と、透過した葉・針葉・花を使う立体的な葉群。マングローブの根、ネザーの幹と樹冠にも対応。
- 原木・木・皮を剥いだ原木／木・幹・菌糸にも適用。建築に使われている同じブロックも丸くなります。皮を剥いだ部分は既存の素材を維持します。

伐採、成長、葉の消滅、ドロップ、当たり判定、セーブ形式はバニラのままです。見た目とブロック単位の当たり判定には差があります。木全体の配置も元のワールド生成に従います。PBRシェーダーや風アニメーションは含まず、現実と同一の描画品質を保証するものではありません。

`./gradlew checkTreeGeometry build` で面の向き、継ぎ目、各接続パターン、素材の透過を検証し、`build/libs/mina-horror-1.1.0.jar` を作成します。生成素材の仕様は [docs/tree-textures.md](docs/tree-textures.md) にあります。

## 光・影・空（シェーダーパック MinaRealism）

Iris（26.3対応版、Sodium必須）を入れて起動すると、同梱のシェーダーパックが `.minecraft/shaderpacks/MinaRealism` に展開されます。「ビデオ設定 → シェーダーパック」で MinaRealism を選ぶと有効になります。Modの更新時には自動で差し替えます。同じ名前でプレイヤーが作ったフォルダは上書きしません。

- 画質：設定画面の「画質プリセット」で 低・中・高 を選べます。影の解像度・距離、各種の光線のサンプル数、雲の細かさが変わります。
- 疑似レイトレーシング：画面内の深度と法線に光線を飛ばし、周囲からの光の跳ね返り（GI）と遮蔽、水・ガラスの反射、接地影を計算します。中・高では既定で有効、低では無効です（個別に切り替え可能）。
- 空：大気散乱（レイリー・ミー・オゾン）で昼の青空、夕焼け、薄明を計算します。太陽・月・星・雲はバニラのものを使わず、すべて自前で描きます。月は満ち欠けと海の模様があり、星は空と一緒に回ります。
- 雲：実際と同じ高さ（雲底約1100、雲頂は最大約2700）に積雲を描きます。天気図が場所ごとの雲の量と高さを決め、3Dノイズ（パーリン・ウォーリー）の塊を細かいノイズで削って、底は平らでちぎれ、上はカリフラワー状にもこもこした形にします。光は雲の中での多重散乱、太陽側の銀色の縁、日陰側の暗い縁（パウダー効果）、上からの空の光と下からの地面の照り返しで計算します。遠くの雲は霞に溶け、高さ約7000には巻雲（すじ雲）が流れます。雨天では暗く厚い雲に覆われ、雷雨ではさらに高く発達します。地面には雲の形どおりの影が落ちます。3Dノイズは `python3 tools/generate_cloud_noise.py` で作り直せます。
- 影：太陽・月の影は、物に接するところではくっきりし、離れるほどぼやけます。水やステンドグラスを通った光には色が付き、葉は光を透かします。
- 表面：テクスチャの明るい部分を盛り上がりとみなし、樹皮・石・土の表面が斜めの光を受けて凹凸を見せます。近くでは細かく、遠くでは自然に消えます（「表面の凹凸」で切り替え、深さも調整可能）。
- 草木：葉・草・花・作物が風で揺れ、影も一緒に揺れます。突風が地表を渡り、雨や雷雨では風が強まります（「風で揺れる草木」で切り替え、強さも調整可能）。
- 水：波の法線、濁りによる散乱と水深に応じた吸収（浅瀬は薄く、深みは青緑）、フレネル反射を計算します。水面越しの水底は波で揺らいで見えます（屈折）。水中では、深さによって日光が弱まり、水底にコースティクス（揺れる光の網目）と光の筋が出ます。遠くは濁りで見えなくなり、水面を見上げると、真上の円の中だけ空が見えて外側は水中が映ります（スネルの窓）。
- 夜：月明かりは実際の比率に近づけ、目の順応にも上限を設けたため、新月の夜はほぼ真っ暗です。暗所では色が薄れて青みがかります（プルキンエ現象）。明るさは「夜の明るさ」で調整できます。夜空には天の川、またたく星、地平線付近の緑がかった大気光が見え、夜から明け方にかけて低地に霧がたまります。
- 雨：雨粒は背景をわずかに屈折させる細い筋として描かれ、太陽や月の方向では光ります。バニラの雨の範囲の奥にも、距離の違う雨の層が見えます。屋外で雨に当たると、画面に水滴が付きます。水滴は背景を小さく逆さに映し、ときどき跡を残しながら流れ落ち、屋根や木の下に入ると少しずつ乾きます（設定の「画面に付く水滴」で切り替え）。降り続くと平らな地面に水たまりができて景色を映し、水たまりと水面には雨粒の波紋が広がります。地面・壁・木は濡れて暗くなり、薄い水の膜が空をぼんやり映して光ります。雨雲は厚く暗くなります。
- 明かり：松明などの光は距離の2乗で弱まり、炎は揺らぎます。明るい光源の周りには光のにじみ（ブルーム）が出ます。
- 霧・カメラ：距離による霞、光の筋（体積光）、水中での吸収、自動露出、ACESトーンマッピングをかけます。テンポラルアンチエイリアス（TAA）で輪郭のギザギザと、雲・霧・光のざらつきを抑えます。レンズの周辺減光と色収差、暗い場所で露出が上がったときのノイズも再現します（それぞれ切り替え可能）。

地形ブロックの写真調テクスチャはまだ含みません。シェーダーは glslang でのコンパイル検証（低・中・高、各機能のオン・オフ）のみ行っており、実機での見た目と負荷の調整は今後行います。`./gradlew checkShaderPackInstall` でパックの展開処理を検証します。
